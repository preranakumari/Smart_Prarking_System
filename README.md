# Smart Parking System 🚗

This project is a Smart Parking System developed using Python.  
It helps users find available parking slots easily and efficiently.

## Features
- Shows available parking slots
- Allows vehicle entry and exit tracking
- Reduces parking search time
- Simple user interface

## Technology Used
- Python
- Tkinter (GUI)
- A* Algorithm (for route finding)

## How to Run the Project

1. Install Python
2. Open project folder
3. Run this command:

python smart_parking_system.py
